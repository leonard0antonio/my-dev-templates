# 📗 W3Schools

**Link:** [https://www.w3schools.com/](https://www.w3schools.com/)

## 📌 Para que serve?
É uma das maiores e mais antigas plataformas de tutoriais e referências para desenvolvimento web. Funciona quase como um dicionário de programação.

## 💡 Por que este link é importante?
* **Consultas Rápidas:** Perfeito para quando dá aquele branco na sintaxe de um método de array no JavaScript ou de uma propriedade específica no CSS.
* **Playground Integrado:** Possui o botão "Try it Yourself", permitindo testar pequenos blocos de código (HTML, JS, SQL) direto no navegador, sem precisar abrir o VS Code.
* **Base Sólida em Dados:** Além do Front-end, tem excelentes guias de consulta rápida para comandos de SQL, PostgreSQL e MySQL, muito úteis na hora de montar ou debugar consultas em bancos relacionais.
