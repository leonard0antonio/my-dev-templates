# 💬 ChatGPT

**Link:** [https://chatgpt.com/](https://chatgpt.com/)

## 📌 Para que serve?
A IA conversacional da OpenAI que popularizou o conceito de LLMs (Large Language Models). Uma ferramenta indispensável de suporte ao desenvolvedor.

## 💡 Por que este link é importante?
* **Pair Programming:** Funciona como um excelente "colega de trabalho" para discutir lógicas de arquitetura, padrões de projeto e destrinchar bugs complexos.
* **Engenharia de Prompts:** Onde você mais vai utilizar os seus templates da pasta `ai-prompts/` para gerar documentações, READMEs e criar testes (QA).
