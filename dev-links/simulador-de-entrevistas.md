# 🎯 Simulador de Entrevistas

**Link:** [https://simuladordeentrevistas.com.br/](https://simuladordeentrevistas.com.br/)

## 📌 Para que serve?
Uma plataforma desenhada para simular perguntas de processos seletivos, ajudando candidatos a praticarem suas respostas para entrevistas técnicas e comportamentais (fit cultural).

## 💡 Por que este link é importante?
* **Treino Prático:** Excelente para se preparar para vagas específicas (como estágios em tecnologia ou residências).
* **Confiança:** Ajuda a organizar o raciocínio na hora de falar sobre projetos do seu portfólio, como o *MentoraTech* ou o *TocaAí*.
* **Feedback:** Permite avaliar os pontos onde você trava para melhorar o seu discurso (storytelling) antes de falar com o recrutador real.
