# 🛠️ Google AI Studio

**Link:** [https://aistudio.google.com/prompts/](https://aistudio.google.com/prompts/)

## 📌 Para que serve?
É a plataforma voltada para desenvolvedores do Google. Permite testar diferentes modelos do Gemini de forma "crua", ajustar parâmetros (temperatura, tokens) e gerar as chaves de API (API Keys).

## 💡 Por que este link é importante?
* **Integração de IA:** Se você quiser colocar inteligência artificial dentro de um projeto seu (ex: um bot no *MentoraTech*), é aqui que você testa os prompts e pega a chave para o seu backend.
* **Controle Total:** Dá muito mais flexibilidade para ajustar como a IA deve responder do que a interface padrão para usuários comuns.
