# 🧜‍♀️ Mermaid.js

**Link:** [https://mermaid.js.org/](https://mermaid.js.org/)

## 📌 Para que serve?
É uma ferramenta baseada em JavaScript que permite renderizar diagramas e fluxogramas usando texto e código, com uma sintaxe muito parecida com o Markdown.

## 💡 Por que este link é importante?
* **Diagramas como Código:** Em vez de desenhar caixinhas em ferramentas visuais, você digita a estrutura e o Mermaid gera a imagem. Isso permite versionar os diagramas junto com o código no Git.
* **Integração Nativa:** O GitHub suporta a renderização nativa de blocos de código Mermaid dentro dos arquivos `README.md`.
* **Uso em Projetos:** É a ferramenta definitiva para documentar a modelagem de banco de dados (Diagramas de Entidade-Relacionamento - MER), fluxos de autenticação, jornadas de usuário e arquiteturas de API diretamente nas documentações dos repositórios.
