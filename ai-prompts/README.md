# 🤖 Meus Prompts de IA para Início de Projetos

Esta pasta contém templates de **Engenharia de Prompts** validados e otimizados para utilizar com assistentes de IA (Gemini, ChatGPT, Claude, Copilot). 

O objetivo é evitar o "problema da tela em branco" no início de um novo projeto, garantindo que a IA receba o contexto exato para gerar código, arquitetura e ideias de alta qualidade e com as melhores práticas desde o dia zero.

## 📂 Prompts Disponíveis

* [**`01-setup-de-projeto.md`**](./01-setup-de-projeto.md): Para gerar a estrutura de pastas, parte visual e lógica base.
* [**`02-modelagem-banco.md`**](./02-modelagem-banco.md): Para criar a modelagem de dados, diagramas MER e scripts de banco.
* [**`03-quebra-de-tarefas.md`**](./03-quebra-de-tarefas.md): Para transformar um objetivo macro em um backlog de tarefas técnicas (Issues).
* [**`04-code-review-e-refatoracao.md`**](./04-code-review-e-refatoracao.md): Para analisar, limpar e aplicar boas práticas em um código existente.
* [**`05-debug-e-solucao-de-erros.md`**](./05-debug-e-solucao-de-erros.md): Para diagnosticar mensagens de erro no terminal e encontrar a correção.
* [**`06-criacao-de-testes-qa.md`**](./06-criacao-de-testes-qa.md): Para gerar testes unitários ou de integração (Caminho feliz e Edge cases).
* [**`07-documentacao-de-funcoes.md`**](./07-documentacao-de-funcoes.md): Para gerar documentação técnica, Swagger ou JSDoc de trechos específicos de código.

## 🚀 Como usar

1. Abra o arquivo do prompt desejado.
2. Copie o texto.
3. Substitua os campos indicados entre `<colchetes>` com o contexto do seu projeto atual.
4. Envie para a sua IA favorita e refine a resposta conforme necessário!
