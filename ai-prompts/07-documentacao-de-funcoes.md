### 4. Prompt 07: `07-documentacao-de-funcoes.md`
Ideal para quando você precisa documentar uma função complexa, uma rota de API ou um componente, usando padrões como JSDoc, Swagger ou apenas um Markdown limpo.

```markdown
# Prompt: Documentação de Código (JSDoc / Swagger)

**Copie o texto abaixo e preencha as informações entre colchetes:**

---

Atue como um Technical Writer e Desenvolvedor. Eu tenho um trecho de código e preciso gerar uma documentação profissional e padronizada para ele, para que outros desenvolvedores possam consumi-lo facilmente.

**Padrão de Documentação Desejado:** <Ex: JSDoc (comentários no código) / Swagger (YAML/JSON para APIs) / README Markdown de Componente>

**Aqui está o código:**
```<linguagem>
<Cole API a aqui componente de função, ou rota>

```

**Por favor, gere a documentação detalhando:**

1. O que o código faz (propósito).
2. Os parâmetros recebidos (tipos, se são obrigatórios e valores padrão).
3. O retorno da função (ou resposta da API, incluindo códigos de status de erro e sucesso).
4. Um exemplo prático e curto de como chamar essa função/rota.
