# 🛠️ Meus Templates e Padrões de Projeto

Este repositório centraliza todos os templates, configurações e padrões que utilizo para manter a consistência, a qualidade e a organização dos meus projetos de software. 

A ideia é não precisar "reinventar a roda" a cada novo repositório, garantindo que boas práticas de documentação e versionamento estejam presentes desde o primeiro commit.

## 🗂️ Estrutura do Repositório

Navegue pelas pastas abaixo para acessar os templates específicos:

* [**`/docs-templates`**](./docs-templates) 📝
  * Padrões para documentação de projetos. Inclui templates de README geral, focados em Frontend, focados em Backend/APIs, além de guias para Issues e Pull Requests.
* [**`/commit-version-templates`**](./commit-version-templates) 🏷️
  * Regras e configurações para o fluxo de versionamento automatizado e mensagens de commit semânticas usando o `commit-and-tag-version`.
