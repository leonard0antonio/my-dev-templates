## 🚀 Como Iniciar

**1. Clone e Instalação:**
```bash
git clone [https://github.com/](https://github.com/)<seu-usuario>/<nome-do-repo>.git
cd <nome-do-repo>
# Para Web:
npm install
# Para Flutter:
flutter pub get

```

**2. Configuração de Variáveis de Ambiente:**
Crie um arquivo `.env` na raiz e adicione a URL da sua API:

```env
VITE_API_URL=http://localhost:3000

```

**3. Execução:**

```bash
# Para React/Vite:
npm run dev
# Para Flutter (escolha o emulador):
flutter run

```
